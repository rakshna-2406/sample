5b) KVM – Create Images from ISO, Image Resizing, and Image Conversion
A. Create VM from ISO
1.	Open Virtual Machine Manager (Virt-Manager). 
2.	Select QEMU/KVM → New. 
3.	Select Local install media (ISO). 
4.	Select the Ubuntu Server ISO. 
5.	Set RAM and CPU. 
6.	Give the VM a name and click Finish. 
7.	Install Ubuntu in the VM. 
B. Create QCOW2 Image
Run:
qemu-img create -f qcow2 ubuntu_vm.qcow2 10G
Check it:
qemu-img info ubuntu_vm.qcow2
C. Resize Image
1.	Shut down the VM. 
2.	Run: 
qemu-img resize ubuntu_vm.qcow2 +5G
3.	Inside the VM, resize the partition: 
sudo growpart /dev/sda 1
4.	Resize the filesystem: 
sudo resize2fs /dev/sda1
D. Convert Image
QCOW2 → VDI:
qemu-img convert -O vdi ubuntu_vm.qcow2 ubuntu_vm.vdi
QCOW2 → VHD:
qemu-img convert -O vpc ubuntu_vm.qcow2 ubuntu_vm.vhd
QCOW2 → IMG:
qemu-img convert -O raw ubuntu_vm.qcow2 ubuntu_vm.img

Exp 8 – Network Virtualization using OpenVSwitch and Linux Bridge
Aim
To perform network virtualization in Linux using Linux Bridge and OpenVSwitch (OVS).
A. Linux Bridge
1. Check network configuration
ifconfig
ip a
2. Install bridge utilities
sudo apt-get install bridge-utils
sudo modprobe bridge
sudo modprobe br_netfilter
3. Create a Linux bridge
sudo brctl addbr br-cloud
4. Add network interface to bridge
Replace enp0s3 with your actual interface name.
sudo brctl addif br-cloud enp0s3
Check:
brctl show
5. Check network and routing
ifconfig
route -n
ip a
________________________________________
B. OpenVSwitch (OVS)
1. Become root
sudo -s
2. Create two network namespaces
ip netns add VRF1
ip netns add VRF2
Check:
ip netns list
3. Create virtual Ethernet pairs
Create first pair:
ip link add veth1 type veth peer name veth2
Create second pair:
ip link add veth3 type veth peer name veth4
4. Attach interfaces to namespaces
ip link set veth1 netns VRF1
ip link set veth3 netns VRF2
5. Assign IP addresses
VRF1:
ip netns exec VRF1 ifconfig veth1 10.10.10.1/24 up
VRF2:
ip netns exec VRF2 ifconfig veth3 10.10.10.2/24 up
Check:
ip netns exec VRF1 ifconfig
ip netns exec VRF2 ifconfig
6. Install OpenVSwitch
apt install openvswitch-switch -y
Start and enable:
systemctl start openvswitch-switch
systemctl enable openvswitch-switch
Check:
systemctl status openvswitch-switch
7. Create OVS switch
ovs-vsctl add-br vSwitch1
Check:
ovs-vsctl show
8. Add virtual Ethernet ports
ovs-vsctl add-port vSwitch1 veth2
ovs-vsctl add-port vSwitch1 veth4
9. Test connectivity
From VRF1:
ip netns exec VRF1 ping 10.10.10.2
If packets are received, the OVS network virtualization is working.
